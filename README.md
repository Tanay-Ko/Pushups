# Pushups 💪

A web-based push-up tracking application built to help users track their workouts, build consistency, and visualize their fitness progress.

<**[🚀 Try Pushups](https://pushups-omega.vercel.app/)**>

## Overview

Pushups is a fitness tracking application designed to make tracking workouts simple and accessible. It combines an interactive user interface with backend data integration to help users monitor their activity and stay consistent with their fitness goals.

## Tech Stack

- **React 19 & TypeScript** – Frontend development
- **Vite** – Build tooling
- **Tailwind CSS 4** – Responsive styling
- **Supabase** – Backend and database integration
- **Recharts** – Data visualization
- **Framer Motion** – Animations and UI interactions
- **Vercel** – Deployment
